## 📝 今の要望

（ここにメモを書いてね）
画面の左右から敵が出てきて、画面の中央に敵が入ってきたら、クリックで倒せるゲームを作りたい。
もう少し敵をカラフルにしてください。
背景を夜にしてください。
敵を倒したら画面にスコアを表示して、倒すたびに点数が増えるようにしたい。
制限時間を１分にしてほしい。
どんどん敵のスピードが上がっていくようにして。
制限時間を取り消して、三回ミスしたら終わりにして。
敵のスピードをもっと速くして。
敵が通り過ぎた場合もミスもカウントしてください
強い敵を出してほしいです。
